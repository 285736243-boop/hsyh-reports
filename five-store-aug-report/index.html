结论与行动

跨路径因果链

流量(路径1) → 活动补贴(路径2/3) → 广告(路径4) → 利润
📊 生意公式：曝光(自然+广告) → 进店率 → 下单率 → 实付 − 补贴(商户承担 75%) − 抽成 = 到手收入 → 减成本 = 利润。5 店 8 月：收入 ¥39,084 / 利润 ¥10,721 / 毛利率 27.4% —— 补贴结构与客单是利润两大漏水点。
