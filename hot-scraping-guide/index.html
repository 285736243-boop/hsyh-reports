三、抓取 → 总结 标准流程（5 步）

① 选源定题：通用热点用头条+百度；科技/AI 用 RSS 92源；财经用头条 finance 分类
② 多源抓取：至少 2 个独立源交叉验证同一热点，记录标题/热度/来源/时间/URL
③ 去噪去重：跨源同题合并（如"印尼7.7级地震"三平台都有→归一条），剔除营销号/重复内容
④ 分类聚合：按领域分桶（时政/国际/财经/科技/体育/娱乐/民生/健康），按热度排序
⑤ 总结提炼：一句话核心洞察 → 3-5 条要点（带来源）→ 分类热点清单 → 背景与影响 → 行动建议

五、踩坑记录（实战验证）

1️⃣ JSON API 远优于 HTML 正则：优先找官方 JSON 接口，HTML 用 readability 而非手写正则
2️⃣ 微博/知乎有反爬 → 不硬刚，换 tophub 聚合源或 RSS
3️⃣ web_search 当前未配 provider → 用 web_fetch 直抓替代
4️⃣ 中文输出：文件写 UTF-8；控制台 GBK 乱码是正常的，文件内容没错
5️⃣ 中文长目录名别硬编码，用 os.walk 动态定位
