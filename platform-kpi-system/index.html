一、外卖平台规则体系

1.1 美团外卖核心规则变化（2025-2026）

🔄 算法从"价格导向"→"品质导向"

  • "明厨亮灶""高分店""特色菜"等品质标签展示优先级提升
  • 对补贴过高商家发出预警，打击虚假补贴
  • 复购率权重提升至20%，复购率高的商家获更多免费流量
  • 全场景覆盖（早餐+正餐+夜宵）门店流量权重比单一场景高92%

📋 营销活动精简（2025）

  • 取消10余项商家营销活动（代金券/提前下单立减/拼单满减等）
  • 治理虚假折扣菜、限购N份起购等5大问题
  • 覆盖200万+外卖商家，减少营销开支16.2亿元
  • 商家信用分系统上线（闪购先行）

🏪 店铺分——流量"准入门槛"

  • 核心考核：营业时间达标率、出餐上报完成率、差评回复率、商家评分
  • 评分低于4.5分→流量降权
  • 需建立24小时差评回复机制
  • 出餐超时直接扣分，建议控制在15分钟内

🆕 2026年新动向

  • 门店"一镜到底"视频上传能力上线
  • 侵权拦截前置到入驻环节
  • 算法公示栏目上线，公开规则原理
  • 取消超时罚款，转向正面激励（安全卡积分体系）

2.2 出价优化策略

💰 CPC出价五步法

  1. 关闭自动出价助手，手动控制
  2. 阶梯测试：每48小时调整10%-15%
  3. 找到CPC拐点（ROI最大化点）
  4. 分时定价：午高峰(11-13点)、晚高峰(17-19点)加价
  5. 新老客定向出价：新店对新客加价30-50%

🎯 推广效果标准

  • 进店率 ≥ 6%
  • 曝光1分钟内达到10次
  • 排名稳定在前25名
  • 对低ROI区域/时段果断止损
  • 长尾关键词精准出价（竞争少，CPC低）

三、流量玩法体系

3.1 流量结构全景图

核心公式：订单量 = 曝光量 × 进店转化率 × 下单转化率 × (1 + 复购率)

这四个变量就是外卖运营的"四个轮子"，缺一不可。

3.2 曝光量获取渠道

🔍 自然流量

  • 搜索排名（关键词优化）
  • 列表页排名（销量+评分+活动）
  • 频道页推荐（分类匹配）
  • 首页推荐（算法个性化）

⚠ 2025年自然流量占比同比下降8%

💰 付费流量

  • 点金推广（搜索竞价）
  • 一站式推广（全站打包）
  • 铂金展位（品牌曝光）
  • 钻石展位（首页banner）

📈 头部商家依赖加深

🏆 活动流量

  • 平台大促（双11/618等）
  • 品类日/品牌日
  • 天天神券/限时秒杀
  • 新店特权（7天加权）

💡 活动加权是自然流量的加速器

3.4 流量获取五步法

  1. 基础优化：菜品头图（专业拍摄点击率+50%）、标题情感化（"深夜放毒必点"）、描述四要素（产地+工艺+克重+辣度）
  2. 搜索排名：优化关键词（如"天河区外卖川菜"），长尾词精准匹配
  3. 活动加权：参与天天神券、限时秒杀等平台活动获得流量加权
  4. 付费推广：点金推广手动调价，分时段/分客群定向投放
  5. 评价管理：引导好评（好评率影响排名权重），差评24小时内回复

五、数据指标体系（完整版）

5.1 外卖运营核心公式（七大板块）

📊 营收板块

交易额 = 曝光人数 × 入店转化率 × 下单转化率 × 购买频次 × 单均价
有效订单 = 总订单 - 退款单 - 异常单
实收 = 交易额 - 优惠金额 - 平台佣金
客单价 = 交易额 ÷ 有效订单

🔄 转化板块

曝光量 = 自然流量 + 付费推广流量
入店转化率 = 入店人数 ÷ 曝光人数
下单转化率 = 下单人数 ÷ 入店人数
复购率 = 复购人数 ÷ 总下单人数

💰 成本板块

营销ROI = 广告带来收入 ÷ 广告成本
CPC = 广告消耗 ÷ 点击次数
订单成本 = 广告消耗 ÷ 订单数
实收率 = 实收金额 ÷ 交易额

📈 增长板块

增长率 = (本期 - 上期) ÷ 上期 × 100%
新客占比 = 新客数 ÷ 总下单人数
老客留存率 = 持续下单老客 ÷ 上月老客
订单量 = UV × P1 × P2 - 取消单

5.2 六大核心诊断指标

1️⃣ 入店率

入店人数÷曝光人数

及格线：7%

2️⃣ 下单率

下单人数÷入店人数

出餐+营业+回复+评分

低→优化出餐/差评回复

4️⃣ 复购率

复购人数÷下单人数

低→会员券/品质/新品

进店率≥6% 排名≤25

6️⃣ 服务数据

准时率+投诉率+接单率

差→出餐效率/包装改进

六、第二轮深度学习成果（20分钟补充）

6.0 店铺分权重体系（深度拆解）

店铺分 = 美团外卖商家综合能力评分（满分100分）

维度权重核心指标计算口径
资质新增20分门店真实性验证(10分) + 后厨环境核验(10分)180天内完成验证，未完成=0分
客服体验~25分差评回复率、在线回复时效近30天数据，需24小时内回复
物流体验~25分出餐上报完成率、配送准时率出餐建议控制在15分钟内
售后体验~15分退款率、投诉率近30天数据
商品体验~15分评分、好评率、差评率近30天有效评价≥10单才计分

店铺等级与流量对应关系

🏆 五级等级制度

  • 王者：体验分>90 + 排名城市品类前10% → 顶级流量
  • 钻石：体验分>80 → 优质流量
  • 黄金：60-80分 → 正常流量
  • 白银：40-60分 → 受限流量
  • 青铜：<40分 → 严重限流

⚠ 限流红线

  • 新店评分 < 4.8 → 限流
  • 老店评分 < 4.7 → 限流
  • 非异率（异常订单比例）过高 → 降权
  • 差评回复率低 → 降分
  • 出餐超时频繁 → 扣分

6.1 广义第二价格拍卖机制（广告投放底层逻辑）

核心规则：排名第1的商家，不按自己的最高出价付费，而是按第2名出价+0.01元付费。

举例：你出价2元排第1，第2名出价1.5元 → 你实际只需支付1.51元/次点击

💰 竞价策略启示

  • 盲目出高价≠多花钱，但能带来高排名
  • 关键是找到CPC拐点（排名上升但成本不暴涨的临界点）
  • 长尾关键词竞争少，出价低也能排第1
  • 高峰期竞争激烈，实际CPC远高于平峰

🎯 实战优化策略

  • 时段博弈：在对手疲劳时出击（下午茶、夜宵时段竞争低）
  • 区域分层投放：高客单区域高出价，低客单区域低出价
  • 菜品组合策略：广告突出高毛利核心品类+限时促销标签
  • 动态预算管理：根据小时级数据实时调整预算分配

6.2 平台补贴成本结构与商家利润

⚠ 关键发现：补贴成本大部分由商家承担

  • "满18减18"优惠券：商家需分摊12-14元（占70%-80%），叠加配送费甚至倒贴
  • 极端案例：42.9元订单，商家承担27.9元补贴，顾客实付0.01元
  • 配送费：美团每单补贴0.5-1元，饿了么按1:2比例补贴（商家承担6元→平台补2元）
  • 佣金率：美团实际商户佣金6%-8%（官方数据），一单30元外卖抽佣约2.4元
  • 算法绑架：不参与活动→降低曝光→订单断崖下跌；参与→单量涨但利润跌

6.3 绝味鸭脖外卖运营参考

  • 小份菜模式：与美团外卖合作推出小份卤味，适应单人/小食场景
  • 热卤杯：4.9元爆款单品，半年内引爆市场，适合外卖低价引流
  • 数字化升级：与腾讯云合作推出"绝智"AI店长系统，营销效率提升2-3倍
  • 私域社群：企微社群+多平台折扣活动，公域流量→私域转化
  • 复合店型：热卤+冷卤+佐餐，多品类覆盖全时段消费场景
  • 2025年营收：54.67亿元，门店逾万家，供应链24小时鲜送到店

6.4 外卖数据分析四大核心方法

🔍 方法一：流量漏斗诊断

逐层分析曝光→进店→下单→复购的转化率，定位"卡脖子"环节

  • 曝光低 → 排名/推广问题
  • 进店率低 → 门面/评分问题
  • 下单率低 → 菜单/价格问题
  • 复购率低 → 品质/体验问题

📊 方法二：对比分析

横向对比（同行/商圈/品类）+ 纵向对比（同比/环比）

  • 同行平均 vs 同行前10%
  • 新客 vs 老客 分别分析
  • 不同时段/区域/品类交叉对比

🧪 方法三：活动ROI评估

评估每个营销活动的投入产出比

  • 活动前后订单量变化
  • 活动带来新客 vs 老客增量
  • 补贴成本 vs 增量利润
  • 活动期间 vs 活动后留存

🔄 方法四：A/B测试验证

小范围验证优化方案，再全量推广

  • 选2-3家相似门店做对照实验
  • 控制变量（只改一个因素）
  • 观察7-14天数据变化
  • 验证有效后再推广到全部门店

6.6 新店运营关键策略

📋 新店30天黄金期

  1. 准备就绪再开启：菜品齐全、图片精美、活动上线之后，再开启7天排名加权（否则转化低导致7天后沉没）
  2. 前14天只看新客下单率：平台新店期重点关注新客转化，需设计新客专享折扣
  3. 评分冲4.8+：新店评分低于4.8会被限流，引导好评至关重要
  4. 配置店铺公告+满减+减配送费：完成3项可额外获得1天新店加权
  5. 商品分类≥5个：丰富度影响权重

七、学习总结与后续规划

7.1 两轮学习总认知（核心认知升级）

🔑 十大核心认知

  1. 平台算法从"价格战"转向"品质战"：复购率权重升至20%，品质标签（明厨亮灶/高分店）获得更多免费流量。单纯烧钱补贴已不是最优解。
  2. 外卖运营=四个轮子驱动：曝光×进店率×下单率×复购率，任何一个轮子掉链子，整体GMV都会受影响。
  3. 广告投放是精细活：点金推广手动出价+分时调价+定向加价。CPC拐点测试、长尾关键词精准出价是ROI提升关键。
  4. 增量在场景拓展：即时零售（万亿市场）、全时段覆盖（权重+92%）、抖音种草、私域复购。
  5. 数据指标体系需场景化：根据新店/冲量/老客/品牌/控本场景匹配不同指标。
  6. 店铺分=流量通行证：满分100分，2026年新增食品安全项(20分)。王者>90分获顶级流量，青铜<40分严重限流。
  7. 广义第二价格拍卖决定实际CPC：排第1按第2名出价+0.01元付费，盲目高出价≠高成本，关键找CPC拐点。
  8. 补贴成本商家承担70-80%：满18减18中商家分摊12-14元，不参与活动则被算法边缘化。
  9. 新店30天黄金期决定生死：前14天看新客下单率，评分需冲4.8+，准备就绪再开启排名加权。
  10. 绝味已走在前沿：小份菜+热卤杯+AI店长+私域社群+复合店型，值得深度对标。

6.2 对后续运作的规划

📋 Phase 1：指标体系升级（近期1-2周）

  1. 补充缺失指标：在当前分析体系中加入入店率、下单率、复购率、店铺分四大诊断指标
  2. 建立基准值对照表：将行业及格/良好/优秀基准值嵌入看板，支持自动对标诊断
  3. 四率联动分析：在Power BI看板中增加"四率漏斗"页面，展示曝光→进店→下单→复购全链路

📋 Phase 2：广告投放优化（中期2-4周）

  1. CPC拐点分析：基于双平台7月数据，分析各分公司/各时段的CPC与ROI关系，找到最优出价区间
  2. 分时段ROI矩阵：建立午高峰/晚高峰/平峰的ROI对比，指导分时调价策略
  3. 长尾关键词挖掘：分析高ROI门店的搜索关键词，推广到其他门店

📋 Phase 3：增量场景探索（中长期1-3个月）

  1. 即时零售品类规划：评估真空包装零食、佐餐调料等新品类在外卖平台的上线可行性
  2. 全时段覆盖分析：分析各门店的时段订单分布，识别可拓展的时段（早餐/下午茶/夜宵）
  3. 抖音渠道评估：调研抖音即时零售入驻条件，评估内容种草+即时配送的ROI
  4. 复购率提升专项：建立会员券+下单返券+社群推送的复购体系，目标老客复购率从当前水平提升至35%+

📋 Phase 4：数据产品化（持续）

  1. 诊断自动化：将六大核心指标+基准值+诊断逻辑写入自动化脚本，一键生成门店诊断报告
  2. 预警系统：入店率<7%或下单率<17%或评分<4.5时自动告警
  3. ROI优化引擎：基于历史数据训练最优出价模型，自动推荐各门店/各时段CPC出价

6.3 与现有分析体系的融合

现有体系：分公司×平台×投放层级×加盟直营 四维度 + 对比/结构/趋势三分析法

新增融合：

  • 在现有四维度上叠加"四率漏斗"（曝光→进店→下单→复购），形成五层分析
  • 将店铺分、差评率、出餐效率纳入门店维度的质量评分
  • 将行业基准值作为看板中的参考线/目标线
  • 将广告投放五步法融入现有的"总部vs门店"投放层级分析
