二、核心计算逻辑（逐环节）

1. 门店明细基础（在用口径）

取「在用门店C补全」全部行 = **在用（有订单）1970 条**（美团819/淘宝688/京东463）
主键 = `平台 + 平台ID`；C门店ID 清洗（去空白/零宽字符 ​‌‍﻿）
唯一实体 884 家 = 店数精准统计表内置（引用不重算）

2. 分公司匹配（V2 新增，⑤×①，键=C门店ID）

C门店库 9,725 家，含**分公司/战区/省区/加盟直营/门店分类**维度
门店明细按 C门店ID left join C库 → 分公司归属
**匹配率 1970/1970（100%）**：原 27 条京东未匹配，已通过「京东秒送id」补录（见第5节）

3. 最新店铺评分（①×②，键=平台+平台ID）

聚合表按 平台+平台ID 去重后 left join → 命中 1,940 条
口径 = 平台官方「最新评分」（店铺分，非单条评价分）

4. 最新评价评分 + 内容（①×③，键=平台+平台ID）

每店每平台取**最新 1 条有内容评价** → 共 727 条（美团426/淘宝247/京东54）
美团兜底：总体评分为空 → 用商品评分
京东：Excel 日期数字用 `unit=D, origin=1899-12-30` 转 datetime；排除"此用户未填写评价内容"占位

5. 27 家京东补录 C门店ID（V2 新增，关键修复）

问题：27 条京东门店明细 C门店ID = "-"（按名称反查 C库 0 命中）
解法：从「三平台有效门店_含C门店ID_20260716-0814.xlsx」取京东**平台门店id** → 与 C库「**京东秒送id**」列直接匹配 → **27/27 全部命中**
补录后分公司分布：江西 +14、广东 +6、陕西 +3、浙江 +2、重庆 +2；未匹配 **0**
教训：京东门店匹配必须走 ID 直查（京东秒送id=平台id），名称反查因全角括号/空格/子品牌后缀差异必失败

6. 差评整改清单匹配（①×④，键=平台+门店名称）

平台名映射：淘宝闪购→淘宝；命中判定：`在差评清单 = 清单差评数非空` → **414 条**
带出：清单差评数/平均评分/原因分布/主要问题/整改建议
416 家中 2 家未命中（名称/平台差异）

7. 回复率（V2 新增，⑥，键=平台+门店名称）

**美团+淘宝**：外卖评价_统一表.csv（16,222 条）→ 列「是否回复」（True=商家已回复）
**京东**：老 xls 读「商家回复」列非空即已回复（198 条评价仅 2 条回复）
门店级回复率 → 按分公司聚合：`回复率 = 已回复评价 ÷ 评价总数`
整体回复率 **69.8%**（16,420 条评价：统一表 16,222 + 京东 198）
匹配分公司 16,236/16,420（98.9%）

8. 评价内容清单（V2 新增）

从门店明细取 727 条有内容评价（评分红≤2/黄=3 标色）→ 网页可搜索 + Excel 全量
Excel 含：分公司/战区/平台/门店/评分/评价内容/在差评清单/主要问题/整改建议

五、已知口径边界

1. **在用 vs 全量**：明细用「在用（有订单）」；差评清单是「全量（含沉默店）」416 家 → 命中 414 条
2. **每店每平台只取 1 条最新有内容评价**，非全量
3. **两种评分含义不同**：最新店铺评分=平台官方店分（聚合表）；最新评价评分=单条评价分
4. **京东评价文件仅 200 行商品级评价**，覆盖门店少（54 条命中）
5. **回复率口径**：美团/淘宝=「是否回复」标记（平台导出）；京东=「商家回复」列非空；京东可能因后台未开通回复而全空
6. **差评匹配键是平台+门店名称**（无ID），名称写法差异会漏（当前漏 2 家）
