6分析总结 · 5大发现

综合路径1-5，8/1-8/17
🥇
发现1｜美团=绝对主力且稳中有升

订单占全店74%，日均订单+8%、入店率/下单转化双升、店铺分97.9、体验分4.91、复购率21.9%——三家平台里唯一健康增长。隐患：客单价-4.5%、商家补贴+16%但订单仅+8%，边际效率下降。

📉
发现2｜淘宝"量跌价升"，属补贴敏感型

订单腰斩(-47%)但客单价+31%至42.8元；8/15补贴加码+到店自取单日冲9单（3.75倍），补贴退坡即回落——流量完全被活动补贴牵着走，且无广告投放对冲。

🧟
发现3｜京东近乎僵尸店

17天仅6单、收入72元、客单价14.8元全店最低，曝光日均61人几乎无存在感；遗留1星差评（鸭头9.9太小）未回复，平台口碑敞口。

📢
发现4｜广告投放收缩且结构单一

美团推广消费-31%（营销魔方占98%），ROI 2.87尚可但规模不足；淘宝广告0投放，流量全靠补贴，两平台推广策略失衡。

💬
发现5｜口碑评价资产薄弱

8月全平台仅4条评价，订单评价率1-2%；好评有（包装/分量/炒饭）但缺积累机制，差评风险已现（京东1星、美团配送不满意）且响应不及时。

7整改举措（按优先级）

目标：美团守盘增效、淘宝恢复流量、京东止损、口碑补短板
P0
处理京东1星差评 + 低客单商品规格整改

①48小时内官方回复该差评（致歉+补偿方案）；②鸭头9.9元规格升级（加大克重或降价至6.9元并明示克重/个数），源头消除"小贵"差评；③同步排查京东上架商品结构——客单价14.8元远低于美团39.3/淘宝42.8，需补齐正餐/套餐类高客单商品。

P0
跟进美团"配送不满意"信号 + 出餐超时

①调取8月初该单配送链路（超时/洒漏/骑手原因），对症优化出餐打包交接；②淘宝8/15-17出现2单出餐超时、单均出餐时长波动，需复核出餐动线（尤其炒饭/卤味高峰）；③差评回复率、消息回复率保持100%不回退。

P0
淘宝补贴节奏重整：稳住8/15验证的"补贴+自取"组合

①以8/15为样板，固定每周"配送费补贴+代金券"双券组合（预算单日≤240元，ROI守住≥2.9）；②砍掉33元级超大额红包（透支利润），改小额高频；③到店自取已开通，配合自取专享价/自取立减培养到店流量。

P1
淘宝恢复曝光：新客承接是核心

曝光-44%是淘宝订单下滑主因：①恢复活动资源位/平台活动报名（神券节等大促节点）；②新客占曝光95%但新客下单转化仅6.8%——上"门店新客立减/首单券"承接；③补齐库存不足商品（8月库存不足27商品项），避免曝光后无货可卖。

P1
美团转化精进：入店率5.93%→7%、客单价止跌

①头图/招牌菜首屏/评分卡（店铺分97.9是现成卖点）优化提升入店；②客单价-4.5%：设计"主食+卤味"套餐组合、满减门槛上移、热销推荐加购引导；③下单转化16.1%已近17%基准，用评价展示/放心吃标识收尾冲刺。

P1
广告结构再平衡：美团加预算、淘宝启动试点

①美团：营销魔方ROI 2.87可加大投放（8月仅523元/日约29元），并测试点金推广（CPC）组合降低单一依赖；②淘宝：选1-2周做小额推广试点（对比纯补贴ROI），验证付费流量对淘宝的拉动。

P2
口碑评价体系：评价率1-2%→5%+

①美团已有"评价返券"代金券机制——扩大投放（当前仅2元券），引导晒图好评；②好评模板化回复+差评24h响应SOP（京东差评教训）；③把"包装干净/分量扎实"固化为差异化卖点文案，主动邀评。

P2
补贴效率日监控

美团8/16补贴251元/12单 vs 8/17补贴130元/5单，单日效率波动大——建立路径1日度补贴ROI看板（订单/补贴），超阈值自动预警，防"补贴依赖症"。
