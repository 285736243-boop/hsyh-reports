二、运行时架构（OpenClaw 引擎）

2.1 Gateway 守护进程

组件职责
Gateway daemon长驻进程，唯一入口，维护所有消息通道连接（WebChat/Telegram/Slack/Discord…）
WebSocket API控制面协议，绑定 127.0.0.1:18789；请求/响应/事件推送（agent/chat/presence/heartbeat/cron）
Canvas HostHTTP 服务 /__openclaw__/canvas/（agent 可编辑 HTML/JS 富渲染）
会话存储~/.openclaw/state/openclaw.sqlite + agents/<id>/sessions/ 转录索引

2.2 Agent Runtime（智能核心）

模块职责
embedded-agent-runnerattempt loop（思考→工具调用→观察→继续）、模型选择、compaction 上下文压缩
sessions会话持久化、技能/提示词/主题资源加载、TUI 工具渲染
agent-tools工具定义与参数 Schema、工具策略（tool policy）、调用前后适配器
agent-hookscompaction 护栏、上下文剪枝（长会话保护）
src/llm模型/Provider 注册表、传输层、流式实现（当前 provider=deepseek）

4.3 一次任务如何贯穿 5 层（实例：合并月报 2026-08-14）

📌 为什么讲这个： 架构图是"静态地图"，真实运行是"一次任务走完一条链路"。以下用今天凌晨的月报合并任务还原完整调用链。
顺序层级动作实际发生的事
①L4任务接收老大哥下达：合并 V13 + 促销定稿 → 分析总结月报，连续优化 3 小时
②L3技能与记忆装载读 waimai-diagnose / analysis-framework SKILL.md；MEMORY.md 注入口径规则（利润/ROI/路径）
③L2数据与计算exec 调 Python(.venv) 读 6 个原始文件（美团CSV GBK + 淘宝XLSX）→ 提取评分/补贴/利润 v2 新洞察
④L1工具策略把关edit 写报告部件（L1 快照级）；脚本运行无需审批；delete 操作走 trash
⑤L3质量保障merge_report.py 结构校验 + verify_numbers.py 83 项数值断言（全 PASS）+ Edge headless 渲染 probe（17/17 图表）
⑥L4交付与发布报告存指定目录（版本 V2）→ 可选 GitHub Pages 发布 → 截图预览 + 汇报
一次任务 = 6 个动作 × 贯穿 5 层；模型（L0）全程驱动：理解需求→选技能→调工具→验结果→写记忆。

6.2 工具策略（Tool Policy）—— 权限分级明细

工具默认级别审批要求可覆盖？
readL0（直接）无—
write / editL1（快照）自动备份原文件是
exec（高风险命令）L2（需确认）人工审批（rm -rf / 等拦截）是
exec（低风险命令）L1（快照）自动记录是
apply_patchL2（需确认）快照备份 + 预览差异是
web_fetchL1（受限）可请求外部 URL；当前网络环境境外站点超时（github 慢/huggingface 断）否
web_searchL1（受限）搜索结果不自动执行否
sessions_spawnL0（直接）记录子会话关系—
cron / scheduleL1（快照）自动保存任务定义是
🔒 红线（R6）： 密钥不写明文 · 删除先 trash · 外发需确认 · 沙箱执行高风险命令
⚠️ 上表为实际使用观测整理（示意），非配置文件原文；真实权限以 openclaw.json 的 tool policy 与运行时的 approvals 为准。

八、🚧 已知缺口 & 演进方向

⬜ 记忆向量化检索 — 当前为全文搜索（grep 风格），无语义检索能力 优先级：高
⬜ 多 Agent 协作拓扑 — 当前为单 Agent 串行处理，无并行/分工机制 优先级：中
⬜ Power BI MCP 与 SQLite 直改一致性保障 — 双写可能不同步，需事务或锁机制 优先级：高
⬜ 技能自动发现与热加载 — 目前需重启 Gateway 才能识别新技能 优先级：中
✅ 报告数值断言（83项） — 已完成，作为质量保障基线 状态：已落地
⬜ 跨会话记忆关联 — 当前每次会话独立，无法自动关联历史相似议题 优先级：低
