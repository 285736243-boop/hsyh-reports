二、四象限诊断法（新增）

2.1 四象限模型定义

高转化率 ↑ 第二象限 │ 第一象限 (低消耗高转化) │ (高消耗高转化) │ ─────────┼─────────→ 高消耗 │ 第三象限 │ 第四象限 (低消耗低转化) │ (高消耗低转化) ↓ 低转化率

2.2 四象限运营策略

  • 第一象限（高消耗高转化）：加码投放 标杆门店，复刻成功经验
  • 第二象限（低消耗高转化）：加大投入 潜力门店，增加曝光
  • 第三象限（低消耗低转化）：诊断整改 营销活动/菜品/装修问题
  • 第四象限（高消耗低转化）：降低出价 调整策略或暂停投放

三、流量健康度模型（新增）

3.1 流量结构评估公式

整体曝光 = 自然曝光 + 广告曝光 ↓ ↓ 健康占比 77.37% 健康占比 22.63% ↓ ↓ 分为：搜索/推荐/自然 分为：斗金/优享大牌/搜索展位 流量健康度判断： 自然占比 > 70% → 健康（品牌力强） 自然占比 50-70% → 正常（广告辅助） 自然占比 < 50% → 不健康（过度依赖广告）

3.2 煌上煌2023年流量结构

  • 整体曝光：20,294万次
  • 自然曝光：15,702万（77.37%）健康
  • 广告曝光：4,592万（22.63%）
  • 广告曝光中：斗金推广 84.50% + 优享大牌 15.47%
  • 建议：强化搜索+推荐曝光获取，目前搜索仅占8.19%

5.2 品牌vs品类对标逻辑

  • 品牌增速 vs 品类增速：品牌增速<品类增速 → 红色预警（市场份额下降）
  • 品牌ROI vs 品类ROI：品牌ROI<品类ROI → 投放效率低于行业
  • 品牌TR vs 品类TR：品牌TR>品类TR → 投入强度高于行业
  • 品牌渗透率 vs 品类渗透率：判断广告覆盖度

六、超会渗透率模型（新增）

6.1 超会（超级会员）健康度评估

超会订单占比 = 超会订单数 / 总订单数 煌上煌：41%（健康水平） 超会渗透率 = 开通超会门店数 / 总门店数 关闭超会的影响： - 交易额下降22.70% - 订单量下降30.20% - 自营销力度下降8.00% - 日均曝光下降32.90% - P2（下单转化率）下降2.20%

6.2 超会关闭的连锁影响

  • 超会关闭 → 日均曝光下降32.90%（流量断崖式下跌）
  • 超会关闭 → 订单下降30.20%（超会贡献订单量大）
  • 超会关闭 → P2（下单转化率）下降2.2pp（转化效率下降）
  • 结论：超会是流量+转化+订单的三重保障，必须保持开通
