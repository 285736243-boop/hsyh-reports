1.2 四大紧急问题诊断

🔴 问题一：79.4%的门店零订单——沉睡门店率极高

  • 7,273家门店中仅1,498家有订单，5,775家零订单
  • 美团5,792家门店中仅815家有订单（14.1%）
  • 淘宝1,481家门店中683家有订单（46.1%）——淘宝有订单率反而更高
  • 根因分析：大量门店可能未开启外卖/未投放广告/菜单未配置

🔴 问题二：评分<4.5的限流门店达253家（占评分门店的50.2%）

  • 评分<4.0的159家——严重限流级别
  • 评分<4.5的253家——触发老店限流红线
  • 典型低分案例：湾里城建广场店(0.48分)/直属系马桩店(0.97分)/惠州乌石店(2.10分)
  • 根因分析：差评未回复、出餐超时、包装漏洒、口味不稳定

🟠 问题三：评分4.8+的优秀门店仅140家（19%）——品质标杆不足

  • 淘宝闪购平均评分仅3.96分，远低于美团(88.88分，不同评分体系)
  • 美团和淘宝使用不同的评分体系（美团100分制，淘宝5分制），需分开分析
  • 淘宝闪购评分<4.5的门店占比更高

🟠 问题四：订单集中度极高——头部效应明显

  • Top10门店贡献了大量订单（赣州公务员小区店美团2,483单+淘宝2,050单）
  • 1,498家有订单门店中，大部分门店日订单量<10单
  • 根因分析：头部门店有专职运营，尾部门店缺乏运营能力

2.1 P0 - 本周紧急（立即执行）

#行动项目标负责人验收标准

逐家检查差评原因（口味/包装/配送），24小时内回复所有未回复差评		 评分回升至4.0+ 区域经理 一周后评分<4.0门店减少50%
2 盘点5,775家零订单门店
检查是否已上线外卖、菜单是否配置、是否开启推广		 识别可激活门店 运营团队 输出激活清单和优先级

调研Top10门店（赣州公务员小区/新建/新村/抚生路等）的运营做法		 形成可复制SOP 运营团队 输出标杆门店运营手册

2.2 P1 - 本月重点（2-4周）

#行动项目标验收标准
1分批激活沉睡门店：优先选择评分4.5+、位于高客流区域的门店，配置菜单+开启点金推广激活500家门店月内新增有订单门店500家
2评分提升专项：对253家评分<4.5门店制定整改计划（差评回复+出餐优化+包装改进+引导好评）评分<4.5门店减少至100家以下月内完成所有门店差评回复
3建立每日数据看板：四率(曝光/进店/下单/复购)+评分+订单+ROI，按分公司/门店维度展示数据驱动决策看板上线并每日更新
4新客套餐设计：为所有外卖门店配置新客立减/首单优惠，降低首次尝试门槛新客下单率提升至10%+新客占比环比提升5%

2.3 P2 - 持续优化（1-3月）

#行动项目标
1全时段场景拓展：推出早餐场景(卤蛋+粥)、下午茶(小份鸭脖+饮品)、夜宵(大份量贩装)权重+92%
2热卤/小份菜测试：选择20家门店试点热卤杯(4.9元引流品)+小份菜套餐验证新产品模式
3私域社群搭建：每门店建立企微社群，配置会员券+下单返券+新品推送复购率提升至25%+
4抖音内容种草：选取10家标杆门店拍摄短视频，展示制作工艺+食材溯源品牌曝光+线上引流

第三部分：外卖运营SOP标准操作流程

3.1 日常运营SOP（每日）

1

开店检查（9:00-9:30）

  • 确认店铺在线状态正常，无异常关店
  • 检查菜单菜品库存，标记售罄菜品
  • 确认满减活动/配送费设置正常
  • 查看昨日差评并回复（24小时内必须回复）
  • 检查今日推广计划是否开启
2

午高峰运营（10:30-13:00）

  • 10:30确认出餐准备就绪
  • 点金推广出价加价30%（午高峰竞争激烈）
  • 实时监控接单→出餐→配送流程
  • 出餐时间控制在15分钟内
  • 处理异常订单（缺货/超时/取消）
3

下午茶时段（14:00-16:30）

  • 14:00降低点金出价（平峰竞争少，可低价获量）
  • 检查午高峰差评，及时回复
  • 更新下午茶推荐菜品（小份/单人份）
  • 补充库存，准备晚高峰
4

晚高峰运营（17:00-19:30）

  • 17:00点金推广出价加价20%
  • 出餐时间控制在15分钟内
  • 重点关注大单/团餐订单
5

收尾复盘（20:00-21:00）

  • 查看当日数据：订单量/曝光量/进店率/下单率/推广消耗
  • 对比昨日/上周同日数据
  • 回复当日所有差评
  • 记录异常情况和明日优化点
  • 更新库存，标记明日推荐菜品

3.2 周度运营SOP（每周）

W1

周一：数据周报 + 策略调整

  • 输出上周运营周报（四率+订单+消耗+ROI+评分变化）
  • 对比商圈同行均值，识别差距
  • 调整本周推广预算和出价策略
  • 检查菜单是否需要更新（季节/库存变化）
W2

周三：活动日运营

  • 美团周三外卖节：参与平台活动，增加推广预算20%
  • 检查神券节/限时秒杀等平台活动日历
  • A/B测试新菜品图或新套餐（选2-3家门店试点）
W3

周五：周末准备 + 竞品扫描

  • 检查周末推广预算是否充足（周末订单通常高于平日）
  • 扫描竞品动态（价格/活动/新品）
  • 准备周末推荐菜品和活动

3.3 月度运营SOP（每月）

M1

月度复盘报告

  • 输出月度运营复盘报告（五段式：摘要→洞察→根因→建议→展望）
  • 分析维度：分公司/平台/门店等级/新老客
  • 四率趋势+ROI变化+评分分布
  • 标杆门店vs末位门店对比
M2

预算调整 + 活动规划

  • 根据上月ROI调整各门店/各平台预算分配
  • 规划下月营销活动（新客/复购/节日）
  • 优化菜单：下架低销量菜品，上线新品
  • 更新菜品图片（月度更新保持新鲜感）
M3

门店评分巡检

  • 逐门店检查评分：<4.0立即整改，4.0-4.5重点关注
  • 检查差评回复率（必须100%）
  • 检查出餐时间是否达标
  • 检查推广效果：暂停低ROI推广，加码高ROI推广

3.4 新店上线SOP（30天）

D1

上线前准备（Day 1-3）

  • ✅ 菜品齐全（分类≥5个，SKU≥20个）
  • ✅ 图片精美（专业拍摄，双视角）
  • ✅ 配置店铺公告+满减活动+减配送费
  • ✅ 设置新客立减/首单优惠
  • ✅ 检查评分基础（引导老顾客先给好评）
D4

开启7天排名加权（Day 4-10）

  • 开启新店特权（第8/12位轮播）
  • 点金推广：新客定向加价50%，日出价预算≥100元
  • 每天监控：曝光量/进店率/新客下单率
  • 前14天只看新客下单率，目标≥10%
D14

冲刺评分4.8+（Day 11-30）

  • 引导好评（包装附感谢卡+好评邀请）
  • 差评24小时内回复（道歉+解释+改进）
  • 出餐时间严格控制在15分钟内
  • 持续优化菜单和价格带
  • 月底目标：评分≥4.8 + 日均订单≥20单

3.5 广告投放SOP

A1

出价策略标准流程

  • ① 关闭自动出价助手，改为手动控制
  • ② 初始出价：参考商圈同行CPC中位数
  • ③ 阶梯测试：每48小时调整10-15%，找到CPC拐点
  • ④ 分时调价：午高峰+30% / 晚高峰+20% / 平峰-20%
  • ⑤ 定向出价：新客+30-50% / 高客单区域+20%
  • ⑥ 止损线：进店率<6%或ROI<3的时段/区域，降低或暂停
A2

推广效果评估标准

指标优秀及格需优化
进店率>10%≥6%<6%
曝光1min次数>20次≥10次<10次
排名前10名前25名25名后
ROI>8≥5<3
订单成本(CPO)<¥1.5<¥3.5>¥3.5

4.1 每日检查清单

☀️ 开店前（9:00）

  • ☐ 满减/配送费设置正常

  • ☐ 今日推广计划已开启

  • ☐ 当日数据已记录
  • ☐ 差评已全部回复
  • ☐ 异常订单已处理
  • ☐ 明日库存已更新
  • ☐ 推广预算复盘
  • ☐ 明日优化点已记录

  • ☐ 评分变化

  • ☐ 差评归类分析
