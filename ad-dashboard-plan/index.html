DAX 度量值设计（可直接参考）：

-- 点击率 CTR = DIVIDE(clicks, displays, 0) -- 每次点击成本 CPC = DIVIDE(cost, clicks, 0) -- 千次展示成本 CPM = DIVIDE(cost, displays, 0) * 1000 -- 利润 Profit = revenue - cost -- 投资回报率 ROI = DIVIDE(Profit, cost, 0) -- 每次点击收入 RPC = DIVIDE(revenue, clicks, 0)

可视化布局：摘要卡片 → 折线图趋势 → 条形图对比 → 散点图矩阵 → 表格明细 → 饼图分布

1.3 开源项目共同优点提炼

  1. KPI 卡片先行：所有优秀仪表板第一行必放 KPI 摘要卡片（4-8 个核心指标）
  2. 对比分析必做：渠道对比、时间对比、区域对比是标配
  3. 趋势+构成+分布三件套：折线图看趋势、饼图看构成、条形图看排名
  4. 交互式筛选器：切片器联动所有图表，而非独立图表
  5. 深色主题为主流：暗色背景+高对比度配色，减少视觉疲劳
  6. 多页导航：概览页 → 详细分析页 → 明细表页，层层下钻
  7. DAX 度量值设计模式：DIVIDE(分子, 分母, 0) 防除零，VAR 变量缓存
  8. 代码化创建趋势：powerbpy/PBIR 格式让仪表板像代码一样可版本控制

四、自动化搭建 Power BI 驾驶舱看板方案

4.1 方案总览

核心思路：使用 powerbpy Python 库 + PBIR 格式，通过代码自动化创建 Power BI 驾驶舱的页面布局、可视化组件和度量值。生成 .pbip 项目文件后，可在 Power BI Desktop 中打开、编辑和发布。

4.2 技术架构

# ============================================ # 自动化 Power BI 驾驶舱搭建技术架构 # ============================================ # 数据层 Excel/CSV 数据源 → pandas 数据清洗 → Power BI 语义模型 ↓ # 自动化层 (Python) powerbpy 库 → 创建 Dashboard → 添加页面 → 添加可视化组件 ↓ # 输出层 .pbip 项目文件 → Power BI Desktop 打开编辑 → 发布到 Power BI Service ↓ # 版本控制 Git (Gitee) 托管 .pbip/.pbir 文件 → 代码化管理仪表板

4.3 环境准备

# 步骤1: 安装 powerbpy（你的虚拟环境已就绪） cd C:\Users\Oo\Desktop .venv\Scripts\python.exe -m pip install powerbpy # 步骤2: 在 Power BI Desktop 中启用预览功能 # 文件 → 选项和设置 → 选项 → 预览功能 → 勾选: # ☑ Power BI Project (.pbip) 保存选项 # ☑ 使用 TMDL 格式存储语义模型 # ☑ 使用增强元数据格式 (PBIR) 存储报表 # 步骤3: 准备数据 # 将双平台7月外卖数据汇总_含门店ID.xlsx 放到项目 data/ 目录

4.4 自动化脚本核心代码

""" automate_dashboard.py 绝味鸭脖外卖广告数据可视化驾驶舱 - 自动化生成脚本 基于 powerbpy + PBIR 格式 """ import pandas as pd from powerbpy import Dashboard # ============================================ # 1. 数据加载与预处理 # ============================================ df = pd.read_excel("data/双平台7月外卖数据汇总_含门店ID.xlsx") # 创建维度表 dim_platform = df[['平台']].drop_duplicates() dim_branch = df[['分公司']].drop_duplicates() dim_level = df[['投放层级']].drop_duplicates() dim_store = pd.read_excel("data/全国门店信息汇总表_v3.xlsx") # ============================================ # 2. 创建 Dashboard # ============================================ dashboard = Dashboard.create( name="绝味鸭脖外卖广告驾驶舱", theme="dark", # 深色主题 data_sources=["data/双平台7月外卖数据汇总_含门店ID.xlsx"] ) # ============================================ # 3. 第1页: 广告效果概览 # ============================================ page1 = dashboard.add_page( name="广告效果概览", layout="grid" ) # KPI 卡片行 page1.add_card(measure="总消耗", title="总广告消耗", format="¥#,##0", position=(0,0)) page1.add_card(measure="总实付额", title="总实付额", format="¥#,##0", position=(1,0)) page1.add_card(measure="综合ROI", title="综合ROI", format="#,##0.00", position=(2,0)) page1.add_card(measure="投放门店数", title="投放门店数", format="#,##0", position=(3,0)) # 分公司消耗 & ROI 对比柱状图 page1.add_chart( chart_type="clustered_bar", axis="分公司", values=["总消耗", "综合ROI"], title="分公司消耗 & ROI 对比", position=(0,1), size=(6,4) ) # 平台消耗占比饼图 page1.add_chart( chart_type="pie", axis="平台", values=["总消耗"], title="平台消耗占比", position=(6,1), size=(3,4) ) # 日趋势折线图 page1.add_chart( chart_type="line", axis="日期", values=["总消耗", "综合ROI"], title="日消耗&ROI趋势", position=(9,1), size=(3,4) ) # 切片器 page1.add_slicer(field="平台", position=(0,5)) page1.add_slicer(field="分公司", position=(2,5)) page1.add_slicer(field="投放层级", position=(4,5)) # ============================================ # 4. 第2页: 平台对比分析 # ============================================ page2 = dashboard.add_page( name="平台对比分析", layout="grid" ) # 平台 × 层级 交叉表 page2.add_table( columns=["平台", "投放层级"], measures=["总消耗", "综合ROI", "订单数", "点击率"], title="平台 × 投放层级 交叉分析", position=(0,0), size=(6,5) ) # ROI 热力图 page2.add_chart( chart_type="heatmap", axis="分公司", legend="平台", values=["综合ROI"], title="分公司 × 平台 ROI 热力图", position=(6,0), size=(6,5) ) # ============================================ # 5. 第3页: 分公司排名 # ============================================ page3 = dashboard.add_page( name="分公司排名", layout="grid" ) page3.add_chart( chart_type="radar", axis="分公司", values=["消耗评分", "ROI评分", "效率评分", "覆盖评分", "增长评分"], title="分公司五维雷达图", position=(0,0), size=(6,5) ) page3.add_chart( chart_type="scatter", x_axis="总消耗", y_axis="综合ROI", legend="分公司", size_field="投放门店数", title="消耗-ROI 气泡图", position=(6,0), size=(6,5) ) # ============================================ # 6. 第4页: 趋势与效率 # ============================================ page4 = dashboard.add_page( name="趋势与效率分析", layout="grid" ) page4.add_chart( chart_type="area", axis="日期", values=["总消耗"], legend="平台", title="分平台日消耗趋势", position=(0,0), size=(4,4) ) page4.add_chart( chart_type="line", axis="日期", values=["点击率", "下单率", "订单成本"], title="效率指标日趋势", position=(4,0), size=(4,4) ) page4.add_chart( chart_type="matrix", rows=["分公司"], columns=["平台"], values=["综合ROI", "订单成本", "点击率"], title="分公司 × 平台 效率矩阵", position=(8,0), size=(4,4) ) # 4.5 DAX 度量值定义

// ============================================ // 广告核心度量值 DAX 定义 // 基于 powerbi-ad-campaign-dashboard 项目优化 // ============================================ // --- 基础度量值 --- 总消耗 = SUM('广告数据'[广告消耗额]) 总实付额 = SUM('广告数据'[广告实付额]) 总订单数 = SUM('广告数据'[订单数]) 总曝光 = SUM('广告数据'[曝光次数]) 总点击 = SUM('广告数据'[点击次数]) 投放门店数 = DISTINCTCOUNT('广告数据'[门店ID]) // --- 效率指标（使用 VAR + DIVIDE 模式）--- 综合ROI = VAR _Revenue = [总实付额] VAR _Cost = [总消耗] RETURN DIVIDE(_Revenue, _Cost, BLANK()) 点击率 = VAR _Clicks = [总点击] VAR _Impressions = [总曝光] RETURN DIVIDE(_Clicks, _Impressions, BLANK()) 下单率 = VAR _Orders = [总订单数] VAR _Clicks = [总点击] RETURN DIVIDE(_Orders, _Clicks, BLANK()) 订单成本 = VAR _Cost = [总消耗] VAR _Orders = [总订单数] RETURN DIVIDE(_Cost, _Orders, BLANK()) 千次曝光成本 = VAR _Cost = [总消耗] VAR _Impressions = [总曝光] RETURN DIVIDE(_Cost, _Impressions, BLANK()) * 1000 // --- 时间智能 --- 昨日消耗 = CALCULATE([总消耗], PREVIOUSDAY('日期表'[日期])) 周累计消耗 = CALCULATE([总消耗], DATESINPERIOD('日期表'[日期], MAX('日期表'[日期]), -7, DAY)) 环比增长率 = DIVIDE([总消耗] - [昨日消耗], [昨日消耗], BLANK()) // --- 层级分析 --- 总部消耗占比 = VAR _HQ = CALCULATE([总消耗], '广告数据'[投放层级] = "总部投放") VAR _Total = [总消耗] RETURN DIVIDE(_HQ, _Total, BLANK()) 加盟消耗占比 = VAR _Franchise = CALCULATE([总消耗], '门店信息'[加盟&直营] = "加盟") VAR _Total = [总消耗] RETURN DIVIDE(_Franchise, _Total, BLANK()) // --- 评分系统（用于综合排名）--- 消耗评分 = RANKX(ALL('广告数据'[分公司]), [总消耗], , DESC) ROI评分 = RANKX(ALL('广告数据'[分公司]), [综合ROI], , DESC) 综合评分 = DIVIDE([消耗评分] + [ROI评分], 2, BLANK())
