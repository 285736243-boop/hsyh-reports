一、外卖平台规则体系

1.1 美团外卖规则全景

🏪 店铺分体系（2026新版）

  • 满分100分，5大维度：资质(20分)+客服(25分)+物流(25分)+售后(15分)+商品(15分)
  • 2026新增：门店真实性验证(10分)+后厨环境核验(10分)，180天未完成=0分
  • 五级等级：王者>90/钻石>80/黄金60-80/白银40-60/青铜<40
  • 评分权重：近期评价权重更高，15字以下低质评价降权

⚠ 限流红线

  • 新店评分 < 4.8 → 限流
  • 老店评分 < 4.7 → 限流
  • 非异率过高 → 降权
  • 差评回复率低 → 降分
  • 出餐超时频繁 → 扣分
  • 排名每提升1位 = 曝光量+7-12%，前3位占同区域42%曝光

1.2 算法转向：从"价格导向"→"品质导向"

  • 复购率权重升至20%，高复购商家获更多免费流量
  • "明厨亮灶""高分店""特色菜"等品质标签展示优先级提升
  • 全场景覆盖（早餐+正餐+夜宵）门店流量权重比单一场景高92%
  • 2025年取消10余项营销活动，覆盖200万+商家，减少营销开支16.2亿元
  • 补贴过高商家发出预警，打击虚假补贴

1.3 淘宝闪购规则特点

  • 2025年饿了么更名"淘宝闪购"，淘宝首页一级入口+饿了么履约网络
  • 从餐饮延伸到3C数码、美妆、医药等即时零售全品类
  • 2026年目标：市场绝对第一，日订单峰值突破1.2亿单
  • 佣金率与美团相近6-8%，配送费补贴1:2比例（商家6元→平台补2元）

1.4 抖音即时零售规则

  • 2026年7月正式入局：抖音超市+小时达合并
  • "内容曝光→兴趣种草→下单→30分钟达"闭环
  • 流量分发逻辑：连锁品牌优先，内容质量决定曝光
  • 劣势：配送网络不成熟、运营经验不足、客服体系待完善

2.2 新店30天黄金期策略

  1. 准备就绪再开启：菜品齐全+图片精美+活动上线后，再开启7天排名加权
  2. 前14天只看新客下单率：平台重点关注新客转化，需设计新客专享折扣
  3. 评分冲4.8+：新店低于4.8会被限流
  4. 配置3项基础：店铺公告+满减+减配送费，额外获1天加权
  5. 商品分类≥5个：丰富度影响权重

三、营销玩法体系

3.1 三大广告产品深度对比

产品定位计费最低预算适合场景ROI特征

3.2 广义第二价格拍卖机制

核心规则：排名第1按第2名出价+0.01元付费。你出价2元排第1，第2名出价1.5元→你实际支付1.51元/次

策略启示：盲目高出价≠高成本，关键找CPC拐点。时段博弈（对手疲劳时出击）、区域分层投放、长尾词精准出价

3.3 补贴成本结构（关键发现）

  • "满18减18"中商家分摊70-80%（12-14元），叠加配送费甚至倒贴
  • 极端案例：42.9元订单，商家承担27.9元补贴，顾客实付0.01元
  • 不参与活动→算法边缘化→订单断崖；参与→单量涨利润跌（两难困境）
  • 美团佣金6-8%，一单30元外卖抽佣约2.4元

五、数据指标体系

5.1 核心四率公式

订单量 = 曝光量 × 进店转化率 × 下单转化率 × (1 + 复购率)

这四个变量就是外卖运营的"四个轮子"，缺一不可。

5.2 30+核心指标速查

📊 营收类

交易额 = 曝光×入店率×下单率×频次×单均价

实收 = 交易额 - 优惠 - 佣金

客单价 = 交易额 ÷ 有效订单

🔄 转化类

入店率 = 入店人数 ÷ 曝光人数

下单率 = 下单人数 ÷ 入店人数

复购率 = 复购人数 ÷ 总下单人数

💰 成本类

ROI = 广告收入 ÷ 广告成本

CPC = 消耗 ÷ 点击次数

CPO = 消耗 ÷ 订单数

CPM = 消耗 ÷ 曝光 × 1000

📈 增长类

环比 = (本期-上期) ÷ 上期

新客占比 = 新客 ÷ 总下单

老客留存 = 持续老客 ÷ 上月老客

六、卤味品类出圈策略

6.1 卤味市场全景

📊 市场规模

  • 2025年卤味市场规模约1620亿元，增速3.7%
  • 全国卤味门店超24万家
  • 连锁化率约25%，CR5(绝味+周黑鸭+紫燕+煌上煌+久久丫)约28%
  • 人均消费25-35元占比最高(29.5%)

👥 消费人群

  • Z世代成主力消费人群
  • 三大细分赛道：休闲卤味/佐餐卤味/热卤
  • 消费场景：追剧零食>朋友聚会>佐餐下饭>办公室下午茶
  • 线上渠道渗透加速，抖音直播成新战场

6.2 绝味鸭脖出圈案例

🔥 五大出圈策略

  1. 热卤杯爆款：4.9元"绝味热卤杯"，半年引爆市场，打破"冷卤"传统认知

7.2 平台选择策略建议

  1. 主力平台：美团——用户基数最大，配送最稳，广告工具最成熟，建议分配60-70%预算
  2. 增量平台：淘宝闪购——即时零售品类拓展(卤味零食/佐餐调料等非餐品类)，分配20-25%预算
  3. 品牌平台：抖音——内容种草+直播带货+品牌曝光，分配10-15%预算，重点做品牌心智
  4. 观望平台：京东外卖——关注品质标签机会，高端线可尝试

8.2 供应链核心竞争力

  • 绝味以供应链先行模式：先建工厂→再开门店，区别于多数品牌"先开店后补供应链"
  • 21座工厂覆盖全国，实现500-800公里就近配送，保障产品新鲜度
  • 三级冷链体系：生产→仓储→配送全链路恒温，支撑短保产品(卤味/新鲜零食)
  • 供应链能力可对外输出：为全行业品牌提供稳定、低成本的短保供货渠道

九、核心结论与行动建议

9.1 十大核心洞察

  1. 平台算法已从"价格战"→"品质战"，复购率权重20%是关键转折点
  2. 外卖运营=四轮驱动（曝光×进店率×下单率×复购率），缺一不可
  3. 广告投放需精细化：广义第二价格拍卖机制下，关键是找CPC拐点而非盲目出价
  4. 补贴成本商家承担70-80%，不参与=算法边缘化，参与=利润被挤压
  5. 增量在场景拓展：即时零售(万亿)+全时段(+92%权重)+抖音种草+私域复购
  6. 绝味已走在前沿：热卤杯+小份菜+AI店长+私域社群+复合店型
  7. 供应链是卤味核心壁垒：21座工厂+三级冷链，先建供应链再开门店
  8. 卤味竞争从"跑马圈地"→"精耕细作"，单店盈利模型比门店数量更重要
  9. Z世代成消费主力，小份菜/一人食/下午茶/夜宵场景是增量关键
  10. 数据指标体系需场景化匹配，形成"看数据→找问题→做优化"闭环
