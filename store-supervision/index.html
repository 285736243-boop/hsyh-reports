外卖门店督导检查与提升工具表

版本：2026 V1 | 适用：美团外卖/淘宝闪购 | 基于15大分析模型 | 生成日期：2026-08-06

使用说明

  • 督导检查流程：按表格7大模块逐项检查 → 对照"标准值"判断是否达标 → 不达标项查"诊断逻辑"找根因 → 按"提升动作"执行整改
  • 颜色标签：红色=不达标需立即整改 黄色=关注项需优化 绿色=达标维持
  • 数据来源：美团外卖商家版电脑版 → 经营罗盘 → 流量/营业/顾客/评价 各模块
  • 检查频率：核心指标每日检查，辅助指标每周检查，综合评分每月复盘

红色预警规则（出现即整改）

  • 店铺分＜75 → 24小时内逐项整改
  • 商家评分＜4.0 → 立即排查差评原因
  • 进店率＜4% → 头图/装修/活动全面检查
  • 下单率＜8% → 菜品/价格/评价全面诊断
  • 老客占比＜8% → 立即启动会员体系建设
  • 商家活动支出率＞50% → 降低满减力度
  • 商责取消率＞3% → 排查缺货/人手问题
  • 超会关闭 → 立即重新开通（关闭即-30%订单）
  • 连续3天订单＜10单 → 全面诊断+BD介入
  • ROI＜2 → 暂停点金推广，调整后再开
