6系统化提升举措大纲（PDCA循环）

🎯 P0 - 紧急修复（1周内）立即

  • 止血亏损点：削减高补贴低产出活动预算30%
  • 头部门店稳住：印象城保持当前策略防止流失
  • 尾部门店扶持：子固路、南山科兴启动紧急新客引流（首单立减¥12）

🚀 P1 - 核心优化（2-4周）重点

  • 菜单重构：删低效SKU(15-20个)+新增引流爆品(3-5个)+套餐占比40%→55%
  • 双平台差异化：美团"品质卤味"品牌故事 vs 淘宝"极速达"30分必达
  • 高峰时段投放：午餐50%+晚餐35%+下午茶10%+夜宵5%预算分配

📈 P2 - 能力建设（1-2个月）推进

  • 会员体系：3级会员(普通/银卡/金卡)，金卡95折+试吃+免运费+生日特权
  • 跨平台防重：手机号后4位匹配，回流专享价，目标重购率25%+
  • 区域差异化：南昌"英雄城限定" ¥28 vs 深圳"加班能量包" ¥32

🏆 P3 - 长期战略（3-6个月）规划

  • 数据基建：BI实时看板+异常预警+A/B测试框架
  • SOP沉淀：新品上架/差评处理/促销活动三大SOP
  • 产品创新：每季2-3款季节限定+竞品爆款跟进+健康低脂线
