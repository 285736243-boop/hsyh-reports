二、运行时架构（OpenClaw 引擎）

2.1 Gateway 守护进程

组件职责
Gateway daemon长驻进程，唯一入口，维护所有消息通道连接（WebChat/Telegram/Slack/Discord…）
WebSocket API控制面协议，绑定 127.0.0.1:18789；请求/响应/事件推送（agent/chat/presence/heartbeat/cron）
Canvas HostHTTP 服务 /__openclaw__/canvas/（agent 可编辑 HTML/JS 富渲染）
会话存储~/.openclaw/state/openclaw.sqlite + agents/<id>/sessions/ 转录索引

2.2 Agent Runtime（智能核心）

模块职责
embedded-agent-runnerattempt loop（思考→工具调用→观察→继续）、模型选择、compaction 上下文压缩
sessions会话持久化、技能/提示词/主题资源加载、TUI 工具渲染
agent-tools工具定义与参数 Schema、工具策略（tool policy）、调用前后适配器
agent-hookscompaction 护栏、上下文剪枝（长会话保护）
src/llm模型/Provider 注册表、传输层、流式实现（当前 provider=deepseek）

2.3 状态与数据目录

路径（相对 ~/.openclaw/）内容
openclaw.json全局配置（通道/模型/工具策略）
state/openclaw.sqlite共享运行时状态库
agents/<id>/agent/*.sqlite模型认证（API Key）+ 运行状态
agents/<id>/sessions/会话转录 + sessions.json 索引
workspace/默认工作区（= C:\Users\Oo\.openclaw\workspace，我的"身体"）
