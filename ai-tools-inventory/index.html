六、如何分享给其他人使用

  1. 复制 Skill 文件夹：把 C:\Users\Oo\.codebuddy\skills\ 下需要的 Skill 文件夹（如 代码小白、小白AI、分析框架、分析模型）复制到对方的 ~\.codebuddy\skills\ 目录
  2. 复制 MCP 配置：把 mcp.json 中需要的服务器配置复制到对方的 CodeBuddy MCP 设置
  3. 复制知识库：把 MEMORY.md 和 references 文件复制，让对方了解项目上下文
  4. 安装配套工具：对方需安装 Python 环境（pandas/pymupdf 等），Power BI Desktop 需本地安装
  5. Power BI 数据文件：需同步 4月15.pbip 项目和数据源 Excel 文件
✅ 最简分享：只需分享「代码小白 + 分析框架 + 分析模型」3 个 Skill 文件夹，即可让对方获得 Power BI 自动化 + 完整分析方法论能力。
